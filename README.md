# Wosmos tap

```bash
brew tap wosmos/tap
brew install furnizsh
furnizsh install
```

| Formula | What |
|---|---|
| [furnizsh](https://github.com/Wosmos/furnizsh) | Fit out a bare shell in one command — Ghostty + zsh + Starship, four themes, 24 commands |
